### Языки

Отвечаем на русском и румынском — и по телефону, и в переписке.

### Возврат

- Срок 2 дня.
- Принимается только деталь с нашей меткой.
- Доставку при возврате оплачивает покупатель.
- Не возвращаются: новые расходники, громоздкие детали и те, что могут испортиться
  при перевозке (мотор точно). Список задаёт владелец флагом на типе детали.
- Вернуть можно маршруткой, привезти самому или почтой.

### Доставка

В любую точку. Способ и цена обговариваются по телефону. Тарифов по зонам нет.

### Валюта

- Сайт для ПМР, основная валюта — рубль ПМР. В нём хранятся и показываются все цены,
  вся админка и все деньги.
- Леев на русской версии нет совсем.
- Леи (L) появляются только на румынской версии, пересчётом по курсу.
- Валюта переключается вместе с языком. Отдельного переключателя валют нет.
- Платить в валюте нельзя.

Курсы владелец вводит сам и редко; точную сумму всё равно подтверждает оператор
по телефону. Стартовые значения (руб. ПМР за единицу):

| Валюта | Курс | Какой это курс |
|---|---|---|
| USD | 16,50 | продажа: столько стоит купить валюту |
| EUR | 18,71 | продажа |
| MDL | 0,8414 | покупка: столько дадут за лей, чтобы цена в леях не вышла дешевле рублёвой |

Владелец может поменять. В админке цену можно ввести в USD или EUR с мгновенным
пересчётом: в интернете цены часто в долларах.

- **Домен `.com`.** Без него нет Search Console, индексации и рекламы. Это блокер SEO.
  Имя выбрать и зарегистрировать.
- **Cloudflare** на домен, бесплатный план.
- **Google Search Console** после деплоя: подтвердить домен, отправить карту сайта.
- **Google Business Profile**: категория «авторазборка», адрес, часы, телефон,
  10+ своих фото площадки. Первых покупателей просить оставить отзыв там.
  По «авторазборка тирасполь» карта стоит выше обычной выдачи.
- **Фото**: площадка и 10–20 доноров целиком (спереди, сбоку, сзади, салон, мотор,
  табличка). Нужны для доноров, заметок и Google Business сразу.
- **Аккаунты** на 999.md и makler.md, когда дойдёт до П24.

## Правила работы с базой и данными

- Рабочую базу не трогать. Проверки — на локальной или изолированной базе.
- Новые миграции только локально; SQL для прода кладём в отчёт.
- Миграции совместимы со старыми записями.
- Сохраняем: ID, связи заказов, движения склада, оригиналы фото, рабочие адреса
  страниц, права и журнал.
- Секреты не коммитить, строку подключения не выводить — только переменная
  `NAA_DB_READONLY`.
- Телефоны в логах и отчётах маскировать.
- Размеры, номера деталей, сроки и обещания не выдумывать: нет данных — поле
  оставить пустым и написать об этом в отчёте.
- Проверки, которые могут сработать не с первого раза (гонки, лимиты, дубли),
  прогонять циклом и писать, сколько прогонов сделано и сколько раз проблема
  воспроизвелась.
- Без `push --force`, `main` не трогать, работа — в отдельной ветке.

## Локальный запуск

```
npm run db:up          # поднять PostgreSQL в контейнере naa-postgres
npm run db:migrate     # накатить db/schema.sql (повторяемо)
npm run seed:catalog   # структура каталога: подкатегории и типы деталей
npm run seed:brands    # справочник брендов
npm run dev            # http://localhost:3000
npm run qa             # снимки витрины на 360–1440 px
node qa/menu-check.mjs qa/shots   # снимки открытого меню каталога
```
