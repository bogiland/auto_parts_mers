## Как отличить тестовые записи

В базе есть штатный признак `demo_tag`:

| Значение | Что это |
|---|---|
| `naa-demo-v1` | демонстрационный набор из `npm run seed:demo` |
| `p1-verify-2026-11-24` | записи, созданные проверками П1 в этой сессии (проставлены после прогона) |
| пусто / NULL | то, что заводили руками аудиторы и владелец |
