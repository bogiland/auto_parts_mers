# NAA.md — набор для мокапа

Полный набор дизайн-спек и HTML-мокапов под твою тему: **автозапчасти Mercedes-Benz**.
Основан на структуре sad.md, но перекрашен под премиум-минимализм: белое / чёрное / красный Mercedes.

---

## Что где лежит

```
naa-md-mockup/
├── README.md                        ← этот файл
├── specs/
│   ├── design-tokens.md             ← все цвета, шрифты, размеры под NAA
│   └── layout-spec.md               ← сетка, шапка, футер, VIN-блок, expert-help
└── pages/
    ├── _shared.css                  ← общий стайл (Inter + красный + dark)
    ├── 01-home.html                 ← Главная: hero Mercedes + плитки + VIN + expert
    ├── 02-catalog-root.html         ← Корневая категория (подкатегории)
    ├── 03-catalog-listing.html      ← Листинг с фильтром по маркам и моделям
    ├── 04-product.html              ← Карточка запчасти + характеристики
    ├── 05-static-about.html         ← Статичка «Despre noi»
    └── 06-not-found.html            ← 404 с большой красной цифрой
```

---

## Главные цвета — конспект

```css
--bg:      #F7F7F7   /* фон */
--surface: #FFFFFF   /* карточки, шапка */
--text:    #1A1A1A   /* заголовки, лого */
--muted:   #8A8A8A   /* второстепенный */
--border:  #EAEAEA   /* границы */

--red:     #E30613   /* акцент: Caută, ошибки, badge active */
--dark:    #1A1A1A   /* CTA-плашка VIN, кнопки Vezi toate */
--green:   #22C55E   /* только badge «в наличии» и корзина-счётчик */
```

**Шрифт**: `Inter` (400/500/600/700/800) — Google Fonts.
**Радиусы**: 8 / 12 / 16 px (крупнее чем у sad.md).
**Letter-spacing**: -0.01em body, -0.02em заголовки.

## Как использовать

1. **Открой любой HTML в браузере** — увидишь работающий макет.
2. **Дай другому Claude:** «Сделай мне landing по этому образцу. Цвета/шрифты из `specs/design-tokens.md`, вёрстка из `pages/`. Оставь palette как есть — она моя.»
3. **Развиваешь дальше:** редактируй `_shared.css` — меняй только токены в `:root`, вся система перекрасится автоматически.

## Что специфично для авто-ниши

- **VIN-поиск** — тёмная плашка на главной, инпут белый + красная кнопка «Caută». Уникальный для automotive элемент.
- **Expert-chat блок** — консультант с аватаром и мессенджер-инпутом.
- **Категории** переработаны под запчасти Mercedes: Motor, Frânare, Suspensie, Transmisie и т.д.
- **Плитки категорий** — с мета-счётчиком «1248 produse» под названием.
- **Фильтр по модели Mercedes** в листинге (C-Class W204, E-Class W212, S-Class W222, GLE).
- **Информационная полоса** на карточке товара — доставка / гарантия / возврат.
- **404** — большая красная цифра «404» + шутка про «дезмембрари».
